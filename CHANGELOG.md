# Changelog

## v1.0.0 — September 2026

First release.

Built a three-page static site for Redgum Tutoring. The homepage covers centre info, hours, and subjects. The enrolment page is a form with client-side validation that calculates the fee rate based on year level. The schedule page loads session data from a JSON file and lets you filter by day.

Added netlify.toml for deployment config and .env.example to document the Formspree endpoint without committing the real value.
